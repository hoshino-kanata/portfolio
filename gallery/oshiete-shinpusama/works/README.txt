works/ — 作品ファイルを置くフォルダ
=====================================

このフォルダは index.html と同じ階層に置いてください。

  index.html
  shinpusama.css
  shinpusama.js
  shinpusama-petals.js
  Gagkline.otf        ← 見出しの書体。CSSに埋め込み済みなので、
                         置かなくてもサイトは動きます（予備）
  lib/                ← 動きのためのライブラリ。必ず一緒に置いてください
    gsap.min.js
    ScrollTrigger.min.js
    three.module.min.js
  works/
    404.txt           ← 本文がまだ無いときに出る文章
    prayer.txt        ← 神父さまの言葉（10本）
    …
    w03.txt
    w04.png
    w005/
      001.png
      002.png
      ...


■ 読み物（言葉・小説）— すべて .txt です
  works/ に .txt（UTF-8）を置いて、shinpusama.js の WORKS に

    { id:"w06", type:"novel", file:"w06.txt",
      title:"…", author:"…", x:"https://x.com/…", date:"2026.09.28" },

  type は 'text'（言葉）と 'novel'（小説）の2つがありますが、
  中身の扱いはまったく同じです。どちらも .txt を読み、読む人が
  文字の大きさと縦書き／横書きを選べます。
  違うのはカードに出る呼び名（言葉／小説）だけなので、
  投稿作品は 'novel'、企画側の文章は 'text' と使い分けてください。

  file を書かない、あるいはファイルが見つからないときは
  works/404.txt の文章が出ます。


■ イラスト（1枚絵）
  works/ に画像を置いて

    { id:"w04", type:"image", src:"w04.png",
      title:"…", author:"…", x:"https://x.com/…", date:"2026.09.02" },

  src はファイル名だけでOKです（works/ は自動で付きます）。


■ まんが
  works/<作品ID>/ に連番の画像を入れます。

    works/w005/001.png
    works/w005/002.png
    …
    works/w005/012.png

  WORKS には枚数だけ書けば読み込まれます。

    { id:"w005", type:"manga", count:12, cover:true, rtl:true,
      title:"…", author:"…", x:"https://x.com/…", date:"2026.09.20" },

    cover:true … 1ページ目を表紙として単独で見せる
    rtl:true   … 右→左にめくる（日本のまんが。省略時 true）
    ext:".jpg" … 拡張子を変える（省略時 .png）
    from:0     … 000.png はじまりにする（省略時 001.png はじまり）

  1枚ずつ指定したいときは pages を使います。

    pages:["w005/hyoshi.png","w005/p01.png", …]


■ 本文の書き方（青空文庫・カクヨム互換）

    ルビ    ｜言葉《ことば》  /  漢字《かんじ》
    傍点    《《ここに傍点》》
    区切り  ＊ や □ だけの行
    空行    そのまま一行あきになります

  ● 挿絵
    画像のファイル名を、1行だけの次のかたちで書きます。

      ［画像：e01.png］
      ［画像：e01.png｜添え書き］

    画像は works/ に置き、ファイル名だけ書けばOKです。
    添え書きは横書きなら下、縦書きなら左に小さな字で出ます。
    半角で [画像:e01.png] や [img:e01.png] と書いても同じです。

    見本として works/sample-e01.png を入れてあります。
    どれかの .txt に

      ［画像：sample-e01.png｜見本の挿絵］

    と1行足すと、どう出るか確かめられます。要らなくなったら
    この画像は消してかまいません。


■ 色について
  何も書かなければ、shinpusama.js の PALETTE から順に割りあてられます。
  指定したいときは c1（アクセント）と c2（副色）の2つだけ書いてください。

    { id:"w04", type:"image", src:"w04.png", c1:"#986fa0", c2:"#6d4a76", … },

  カードの地の色と、夜の配色で使う明るめの色は c1 から自動でつくります。
  モチーフの図柄は motif:"halo" のように選べます。
  選べるのは halo / arch / moon / star / rose / flame / drop / grid の8つで、
  省略すると順番に割りあてられます。


■ 昼と夜
  ヘッダーの ☀ / ☾ で切り替わります。選んだ状態はブラウザに残ります。
  一度も押していないあいだは、閲覧者のOSの設定に従います。


■ 読み物の操作（読む人ができること）
  文字の大きさ（小/中/大）と組み方向（縦/横）を選べます。
  つまみは、はじめの演出のあいだは出ていません。
  本文が現れると、PCなら画面右の中央、スマホならフッターの左側に
  ふわりと現れ、読んでいるあいだはそこに出たままです。
  途中で変えても、読んでいた位置のまま組み直されます。
  選んだ状態はブラウザに残ります。

  縦書きは、PCならホイールか左右キー、スマホなら横にスワイプして
  読みすすめます。スマホで本文の上を縦に払ったときは、ページのほうが
  動きます（本文の上で止まりません）。


■ 画面の送り方
  PC  … ヒーローも Confession も、縦にスクロールすると横へ流れます。
  スマホ … 横に払うと中身が変わり、下にスクロールすると次の章へ進みます。
          ヒーローを横に払う → 作品が変わる
          ヒーローを下へ     → Confession へ
          カードを横に払う   → カードが送られる（1枚ずつまんなかで止まる）
          カードを下へ       → About へ
          読み物を横に払う   → 縦書きが読みすすむ
          読み物を下へ       → ページが動く


■ 浮いている紙片について
  スマホでは、ヒーローのあいだは濃さを保ち、Confession が画面に
  乗ってから消えていきます。PCはヒーローが貼りついて長いので、
  Confession が近づいてから消え始めます。


■ アップロードするとき
  lib/ フォルダを忘れずに一緒に上げてください。
  ここにサイトの動きを支えるライブラリが入っています。外部の配信元
  （CDN）には一切頼っていないので、通信環境に左右されません。
  逆に lib/ が無いと、読み込み中の画面のまま止まってしまいます。

  index.html を直接ダブルクリックで開くと、
  ・浮いている紙片（shinpusama-petals.js）
  ・本文（works/*.txt）
  の2つが読み込めません。ブラウザの決まりごとによるものです。
  サーバーにアップロードすれば、どちらも問題なく動きます。
